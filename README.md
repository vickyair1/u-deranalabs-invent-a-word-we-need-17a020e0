# Invent a Word We Need

One new English word with a one-line definition (78 characters), entered in the [make.fun bounty](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0).

> miswave (n.) — waving back at someone who was waving at the person behind you.

**Why this word:** everyone has done it — you wave back, warm and confident, and then the stranger's hand sails past you toward the person behind you. English has no word for that small public cringe. *Miswave* is built from mis- + wave, on the pattern of *mistake* / *misread*, so it sounds like English could have grown it: sayable, spellable, memorable.

**Usage:** "I miswaved at the barista this morning — she was waving at the regular standing behind me."

`main.py` writes the line to `/output/entry.txt` and prints it to stdout. Deterministic: byte-identical output on every run.

## Run

```sh
python3 main.py
```
